# 🤖 Autonomous Agent System

This directory houses the skills, operational workflows, and orchestration guides for AI agents collaborating on ProofRoute.

---

## 📂 Structure

- **`AGENTS.md`**: Master rules and role-to-directory mappings.
- **`skills/`**: Domain knowledge files (`SKILL.md`) for backend, frontend, blockchain, ML, indexer, testing, and git.
- **`workflows/`**: Step-by-step procedures for feature development, bug fixing, API changes, and releases.
