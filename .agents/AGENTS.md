# Agent System Configuration

This directory contains the skills, configurations, and workflows used by autonomous AI agents operating in the ProofRoute repository.

## 📂 Subdirectories
- `skills/`: Specialized domain knowledge instructions for specific tech stacks.
- `workflows/`: Step-by-step procedures for standard engineering tasks.

## 📜 Agent Guidelines
1. Read relevant `SKILL.md` before executing domain tasks.
2. Follow workflows defined in `workflows/`.
3. Never bypass quality gates or commit broken tests.
