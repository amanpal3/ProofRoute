# Release Workflow

1. **Version Bump**:
   - Update version numbers across package manifests.
2. **Changelog**:
   - Move unreleased items to the new version section in `CHANGELOG.md`.
3. **Pre-release Audit**:
   - Run full test suite and security scan.
4. **Deployment**:
   - Follow `docs/DEPLOYMENT.md` for target environment releases.
