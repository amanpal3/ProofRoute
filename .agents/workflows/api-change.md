# API Change Workflow

1. **Contract Draft**:
   - Update `docs/API_CONTRACT.md` with proposed endpoint modifications.
2. **Backward Compatibility Check**:
   - Ensure changes do not break active frontend or external clients.
3. **Backend Implementation**:
   - Update routes, schemas, and service layer.
4. **Client & Test Updates**:
   - Update frontend API clients, mocks, and integration test suites.
