# Feature Development Workflow

1. **Requirements & Spec**:
   - Check or write feature spec in `docs/` or `.gsd/`.
2. **Implementation**:
   - Develop changes in designated directory (`contracts/`, `backend/`, `frontend/`, or `ml/`).
3. **Testing**:
   - Add unit and integration tests.
   - Ensure 100% passing tests across touched packages.
4. **Documentation**:
   - Update `docs/API_CONTRACT.md`, `README.md`, or architecture docs if interfaces changed.
5. **Review & Verification**:
   - Verify against quality gates.
