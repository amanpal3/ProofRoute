# Bug Fix Workflow

1. **Reproduction**:
   - Create a failing test reproducing the reported issue.
2. **Root Cause Analysis**:
   - Identify the flaw in logic, state, or contract interactions.
3. **Fix**:
   - Apply minimal and robust fix.
4. **Verification**:
   - Verify the reproduction test passes alongside existing test suites.
5. **Log**:
   - Document root cause and resolution in `CHANGELOG.md`.
