# Frontend Skill Guide

## 🛠️ Tech Stack & Standards
- Framework: Next.js (App Router), React, TypeScript
- Styling: Tailwind CSS, Radix UI / shadcn/ui
- Web3: Wagmi, Viem, RainbowKit

## 📌 Rules
- Use responsive, accessible, mobile-first design.
- Implement clear loading and error states for all Web3 transactions and API calls.
- Adhere to design tokens specified in `docs/UI_UX.md`.
