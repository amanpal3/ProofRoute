# UI / UX Design Specifications

## 🎨 Design Tokens & Theme
- **Color Palette**:
  - Primary: Deep Indigo / Slate (`#0F172A`, `#1E293B`)
  - Accent / Trust: Emerald Green (`#10B981`)
  - Warning / Risk High: Crimson Red (`#EF4444`)
  - Neutral Background: Soft Cool Gray (`#F8FAFC`)
- **Typography**: Inter / Plus Jakarta Sans for high legibility.

---

## 📱 Core User Flows

1. **Public Verification Flow**:
   - Landing page -> Drag & drop document -> Instant SHA-256 hashing in browser -> API verification -> Visual status badge & certificate breakdown.
2. **Issuer Dashboard**:
   - Connect Web3 Wallet -> Batch Upload Documents -> Sign transaction -> Track on-chain anchoring status in real time.
3. **Risk & Anomaly Inspector**:
   - View document side-by-side with ML heatmap highlighting potential modified regions.
